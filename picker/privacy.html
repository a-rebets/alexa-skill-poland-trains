My Train Schedule

Privacy policy

Last updated: 22 October 2026.

My Train Schedule is a free Alexa skill that reads train departures and arrivals for stations you choose. The timetable currently covers only Poland. It is an open-source personal project by Artem Rebets; the code is at github.com/a-rebets/alexa-skill-poland-trains. This policy covers the skill and this station picker.

What the skill does not collect

The skill does not ask for your name, email address, phone number, location, or contacts. It has no user accounts and no database of users. This page does not use cookies, analytics, or tracking, and it loads nothing from other sites.

The account-linking token

When you link the skill, this page hands Alexa an access token. The token contains the station codes you selected and, if you turned some off, the direction codes you kept, including whether long-distance trains are included. If you paste an ElevenLabs API key, that optional key is part of the same token. Station and direction codes are public timetable identifiers.

Alexa stores the token on your Amazon account and sends it to the skill with each request. The skill reads it to know which stations to look up and does not save it anywhere. The key is typed into this page, is not saved in your browser, and leaves only inside the token. To remove the token, disable the skill or unlink it in the Alexa app. To change stations, link it again.

Requests to the skill

The skill runs as an Alexa-hosted skill on Amazon Web Services. Amazon sends it each request, including an anonymous Alexa user ID and the token. The skill uses the user ID only within that request and does not store it.

The skill writes a short technical log line for each request to Amazon CloudWatch: timings, whether live data and the natural voice were used, and the length of the spoken text. It does not log the token, the key, your stations, or your user ID. Error reports, if any, contain the program error and stack trace. Amazon's own platform also records the request ID and duration. Those logs stay in the Alexa-hosted account under Amazon's settings.

Natural voice (ElevenLabs)

Only if you supplied an ElevenLabs key, the skill sends the text of the answer (train times, station and destination names) to ElevenLabs with your key, to turn it into speech. Nothing else about you is sent. ElevenLabs bills that use to your ElevenLabs account and handles the request under its own privacy policy. Without a key, the standard Alexa voice is used and ElevenLabs is not contacted.

The resulting audio is stored in the skill's Amazon S3 bucket under the current day (Europe/Warsaw), so the same answer can be replayed without calling ElevenLabs again. A clip contains only the spoken timetable text. It is named by a hash of the voice, model, and text, not by user, so it is not linked to you or your key. Clips from previous days are deleted automatically.

Timetable data

Timetable data is published by PKP Polskie Linie Kolejowe S.A. and assembled as GTFS by Mikołaj Kuranowski. Live delay data comes from that same feed. The skill downloads these public files; it sends nothing about you to them.

Children

The skill is not directed at children and does not knowingly collect information from them.

Changes and contact

Changes to this policy are published on this page and in the repository history. For questions, open an issue at github.com/a-rebets/alexa-skill-poland-trains/issues.
